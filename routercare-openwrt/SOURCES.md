# Источники и статус интеграции

Дата сверки: 18 октября 2026 года.

## Принципы

OpenWrt Zapret — собственная диагностическая панель для OpenWrt. Внешние движки остаются отдельными upstream-проектами; их код, данные и товарные знаки не выдаются за наши. Панель по умолчанию работает read-only и не меняет firewall, DNS, hosts, службы или VPN.

## Что доступно в версии 0.5.14

- **Состояние Zapret v1, Zapret2 и Mihomo:** только наличие/статус службы по локальному read-only CGI. Совместное состояние Zapret и Zapret2 вызывает предупреждение, не автоматическое переключение.
- **Mihomo:** отдельная локальная проверка синтаксиса фиксированного YAML командой mihomo -t; конфигурация и вывод с секретами не показываются. Это не тест соединения/скорости.
- **Список доменов:** браузерная проверка формата ASCII-доменов, дубликатов и пустых/комментариев строк. Не выполняет DNS/HTTP-проверку; введённое значение не сохраняется и не передаётся.
- **Диагностическая консоль:** только четыре фиксированные команды. `status` читает существующий статус CGI, `config-test` запускает существующую проверку Mihomo с итогом без конфига и секретов. Это не shell: команды, аргументы, установку и изменения выполнять нельзя.
- **Цветовые варианты:** десять локальных акцентных наборов; выбранный вариант сохраняется только в localStorage этого браузера. Основной кобальтовый вариант остаётся значением по умолчанию.
- **Справка по стратегиям, модулям и протоколам:** хранится в этом файле, чтобы основной экран показывал только доступные действия. Ссылки ведут к upstream и не означают, что импорт или применение реализованы.

## Компоненты, которые ещё не интегрированы

Zapret-Manager документирует дополнительные модули и функции: Steer, Forkozz, ByeTube, TG WS Proxy, Mixomo, Hosts, DNS over HTTPS, AmneziaWG, рекламные списки, подбор стратегий и разделы диагностики. Наличие этих пунктов в upstream не означает их наличия в OpenWrt Zapret. Для каждого нужна отдельная проверка протокола, поставки, лицензии, зависимости, API и отката; текущая панель не устанавливает и не переключает их.

Импорт подписок и генерация/настройка WARP не реализованы. Реальные URL подписок, UUID, пароли, ключи и конфигурации пользователя запрещено добавлять в репозиторий или снимки.

## Запланированные этапы

1. Прочитать конфигурацию Zapret2 и показать найденный профиль без записи; добавить поддержку конкретной версии движка только после проверки формата.
2. Добавить проверку происхождения и целостности выбранных списков до редактора/обновления.
3. Для VPN-конфигов сначала определить фактически установленную сборку Mihomo и поддерживаемые схемы; импортировать секреты только в локальный защищённый файл на роутере.
4. Любое изменение на роутере вводить отдельным действием с резервной копией, валидацией, подтверждением и откатом.

Работа с живым роутером и установка/удаление пакетов здесь не выполнялись.

## Не помещать в Git

- URL подписки и ключи провайдера;
- UUID, пароль, приватные ключи, controller secret и токены;
- пользовательский YAML, если он содержит секреты;
- диагностические скриншоты с IP-адресами, устройствами, именами Wi-Fi или ключами.
