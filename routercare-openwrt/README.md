# OpenWrt Zapret

Лёгкая русскоязычная панель для Xiaomi AX3000T с OpenWrt 25.12.x. Проект
использует готовые движки Zapret и Mihomo; собственный DPI-движок не пишется.
В текущей версии реализована безопасная диагностика уже установленных служб и
проверка Mihomo-конфига штатной командой `mihomo -t` и браузерная проверка формата списков доменов.
Последняя не выполняет DNS/HTTP-запросов, не сохраняет введённое и не применяет данные.
Изменение конфигов не выполняется.

## Возможности версии 0.5.15

- Светлый интерфейс с компактной навигацией, белыми карточками и десятью вариантами цветового акцента.
- Добавлены десять цветовых вариантов панели: основной кобальтовый, Apple Frost, аметист, океан, мята, изумруд, роза, янтарь, коралл и графит. Выбор применяется только в браузере и сохраняется в его `localStorage`.
- Добавлена терминальная по виду диагностическая консоль. Доступны только `help`, `status`, `config-test` и `clear`; команды оболочки, аргументы и любые изменения роутера заблокированы. Это локальный интерфейсный помощник, а не shell/Termux.
- Основной экран очищен от дублирующих переходов и справочных карточек по неподключённым протоколам/модулям. Подробные источники и совместимость остаются в `SOURCES.md`.
- При работающем Zapret v1 панель показывает только распознанные метки стратегии из локального `/etc/config/zapret`; это не применение профиля и не гарантия доступности.

Zapret v1 отображается как legacy для диагностики старых установок. Для новой настройки используется Zapret2; одновременно запускать два перехватчика не рекомендуется. Панель показывает предупреждение при обнаружении обоих активных служб, но не включает, не переключает и не останавливает их.

- Показывает модель, версию OpenWrt, архитектуру, свободное место `/overlay` и
  состояние служб Zapret, Zapret2 и Mihomo. Статус init-службы/процесса не является проверкой прохождения трафика.
- Проверяет найденный Mihomo YAML командой `mihomo -t`; выводит только итог,
  не печатая конфиг, URL подписки и диагностический вывод. Успешный тест не означает,
  что VPN-узлы доступны или что трафик проходит через туннель.
- Работает локально: интерфейс и CGI находятся на роутере, внешние библиотеки,
  CDN, аналитика и телеметрия не используются.
- Только читает состояние. Не редактирует firewall, DNS, hosts, VPN или конфиги.
- Не открывает новые порты и не меняет настройки uhttpd.
- Не включает в исходники конфигурацию VPN, URL подписки, токены или пароли.

## Zapret2: проверенная сборка

Workflow GitHub Actions собирает официальный Zapret2 `v1.0.5.2` через SDK OpenWrt `25.12.5` для `mediatek/filogic`, совпадающий с текущей системой роутера. Артефакт содержит только APK-пакеты `nfqws2`, `mdig`, `ip2net` и `SHA256SUMS`; полный конфиг, списки стратегий и fake-файлы в архив не входят.

Пакеты добавляют исполняемые файлы в `/opt/zapret2/binaries/my`. Для использования нужна подготовленная базовая установка Zapret2 по инструкции upstream. Не запускайте одновременно два DPI-перехватчика; перед переключением проверьте действующий сервис и предусмотрите откат. Сборка проверена в CI, но на живом роутере не устанавливалась.

## Источники и план интеграции

Сверку модулей и статус интеграции версии 0.5.15 см. в [SOURCES.md](SOURCES.md).

- Zapret и стратегии: [StressOzz/Zapret-Manager](https://github.com/StressOzz/Zapret-Manager)
  и upstream-компоненты, на которые он ссылается. Код менеджера не копируется.
  Upstream помечает Zapret v1 как EOL; новые интеграции ориентируем на Zapret2,
  не смешивая конфиги и профили двух движков.
- Mihomo: отдельная служба и существующий конфиг роутера. Проверка `mihomo -t`
  доступна в панели; резервное копирование и редактирование конфигурации
  добавим отдельным этапом, не затрагивая `/etc/mihomo/config.yaml` сейчас.
- Секреты вводятся локально на роутере и исключаются из Git. Не добавляйте в
  репозиторий URL VPN-подписки, UUID, пароли, `secret` контроллера или ключи.

Подробности совместимости компонентов и этапов — в [SOURCES.md](SOURCES.md).

## Установка

1. Распакуйте архив на компьютере.
2. Скопируйте папку `routercare-openwrt` на роутер, например в `/tmp`.
3. Подключитесь к роутеру по SSH и выполните:

   ```sh
   cd /tmp/routercare-openwrt
   sh install.sh
   ```

4. Откройте `http://АДРЕС-РОУТЕРА/routercare/`. Если роутер доступен по
   `192.168.10.1`, адрес будет `http://192.168.10.1/routercare/`.

Установщик копирует только страницу в `/www/routercare/` и два read-only CGI
для статуса и проверки Mihomo. Перед заменой существующих файлов он сохраняет
их в `/root/routercare-backup/`. Скрипт завершится с ошибкой, если не найдёт
поддерживаемый CGI-путь; он не будет менять настройки веб-сервера автоматически.

## Удаление

Из распакованной папки запустите `sh uninstall.sh`. Удаляются только файлы
OpenWrt Zapret. Резервные копии остаются в `/root/routercare-backup/`.

## Обновление и сопровождение

В 0.5.15 нет автообновления: обновление выполняется заменой файлов новой версией
после проверки изменений. Это намеренно — обновляющий код не запускает shell
скрипт с удалённого сервера автоматически. Версия и список изменений указаны в
этом README. Дальше можно добавлять резервное копирование конфигов и управляемые
действия с подтверждением и откатом, но только после проверки текущей установки.

## Ограничения

- Страница доступна на том же HTTP/HTTPS адресе, что и веб-сервер OpenWrt.
  Используйте её только в доверенной домашней сети; не публикуйте панель в
  интернет.
- Состояние службы определяется init-скриптом или наличием процесса. Для
  нестандартных имён служб вывод может быть «не обнаружена».
- Эта версия не включает обход DPI и не меняет маршрутизацию.
